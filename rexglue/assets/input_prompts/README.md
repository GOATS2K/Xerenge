# Input prompts

Button and key icons for the game's button hints, one folder per controller
family: playstation, xbox, switch, steamdeck, keyboard (the 64 px "Default"
size).

From [Input Prompts 1.5](https://kenney.nl/assets/input-prompts) by Kenney
(www.kenney.nl), CC0 1.0 - see License.txt. None of it comes from the game.
